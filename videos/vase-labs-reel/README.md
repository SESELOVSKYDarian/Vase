# Reel Vase Labs

Reel vertical 1080x1920, 30 fps, 33 s, con música original generada en código (120 BPM).
Los cortes caen en cada compás (ver `CUTS` en `src/theme.ts`) y los efectos de sonido siguen lo que pasa en pantalla.

- Previsualizar: `npm run studio`
- Música: `npm run music` → `public/musica.wav`
- Render completo: `npm run render` → `out/vase-labs-reel.mp4`
